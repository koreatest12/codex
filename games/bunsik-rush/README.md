# 분식 러시

Flask 컨테이너에 통합된 한국어 음식점 경영 게임입니다.

## 실행

저장소 루트의 기존 `README.md` 절차대로 보안 환경변수 및 파일 기반 키를 설정하고 `docker compose up --build -d`를 실행합니다. 서버 홈에서 보안키로 인증한 뒤 **분식 러시 게임 실행**을 누르거나 `/game/`으로 이동합니다. 기본 로컬 주소는 `http://localhost:8080/game/`입니다.

게임 페이지는 인증되지 않은 사용자를 홈으로 보냅니다. `/api/game/health`는 인증된 세션만 허용하며 다른 API와 같이 기존 보안 헤더를 적용합니다. 게임 자체는 브라우저에서 실행되므로 점수는 서버 권한이나 개인정보 접근에 사용되지 않습니다. 진행은 열린 화면에서 유지되며 새로고침 시 초기화됩니다.

## 포함 기능

- 떡볶이·김밥·라면·만두·햄버거·피자와 새 메뉴 해금.
- 여러 그릇 주문, 3그릇 묶음 조리, 메뉴별 최대 5개 작업 동시 조리 및 25그릇 보관.
- VIP 팁, 포장 표시, 평판, 연속 판매, 일별 매출 목표 및 보너스.
- 조리 도구 Lv.12, 카운터 확장, 주방·판매 직원, 재료 보충.
- 설정별 자동 구매. 재료비 10,000원을 남기며 시설·직원·메뉴를 구매.
- 자동 요리·판매, 다음 날 자동 영업, 일시정지, 화면 이탈 시 자동 일시정지.
- 새 손님을 최소 2초간 표시한 뒤 자동 판매. 카드를 유지하면서 상태만 갱신.
- 오리지널 32초 / 120 BPM BGM, 반복 재생, 음악 켜기·끄기, 볼륨 조절.
- 실제 서버 건강 응답을 10초마다 측정하고 HTTP 상태·응답 지연·성공률·지연 그래프 표시.
- 현재 브라우저의 처리 주기·평균 처리 시간·최대 지연·주문/작업 수·오류와 지원되는 JS 메모리 표시.

서버 CPU, 전체 접속자 수, 컨테이너 RAM 등 측정하지 않는 값을 생성하지 않습니다. 연결 실패나 인증 만료는 모니터링에 표시하며 이미 로드된 로컬 게임은 계속 실행할 수 있습니다. 상태 확인 API는 비밀 키·환경변수·개인정보를 반환하지 않습니다.

## 검증

Node.js 24 권장. 게임은 외부 npm 의존성이 없습니다.

```bash
npm --prefix games/bunsik-rush run check
npm --prefix games/bunsik-rush test
PYTHONPATH=app python -m unittest discover -s tests -v
```

게임 테스트는 10개 재현 가능한 난수 시나리오에서 여러 영업일을 진행하며 자동 구매 설정, 재료·보관 한도, 병렬 조리, 직원, 일시정지를 검사합니다. Flask 테스트는 게임 및 모니터링의 인증 조건, 정적 자원과 BGM 범위 요청, 기존 개인정보 API의 인증 조건을 검사합니다. `COPY app/`로 게임 HTML·JS·CSS·BGM이 기존 이미지에 포함됩니다.

## 파일

- `app/templates/game.html`: 게임 화면
- `app/static/bunsik-rush/`: 엔진·화면 코드·CSS·BGM
- `app/server.py`: `/game/`, `/api/game/health`
- `tests/test_game_routes.py`: 통합 및 인증 테스트
- `games/bunsik-rush/tests/engine.test.mjs`: 엔진 테스트

BGM은 직접 합성한 오리지널 음악입니다. 필요하면 Python과 NumPy로 `scripts/make_bgm.py`를 실행해 WAV를 생성하고 ffmpeg로 MP3를 만들 수 있습니다. 이는 개발자용 재생성 기능이며 게임 실행에는 NumPy나 ffmpeg가 필요하지 않습니다.
