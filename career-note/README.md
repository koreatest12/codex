# Career Note — 이력서·포트폴리오 관리

한국어 이력서, 경력, 학력, 프로젝트, 지원서 보관 서비스입니다.

## 기능
- PDF/DOCX/TXT/MD 업로드 시 원문 기반 이력서·포트폴리오 초안 생성
- D1 기록 저장, R2 첨부파일 저장, JSON 백업/복원
- PDF 인쇄, 상태 점검, 읽기 요청 제한적 재시도
- 서버 프로세스 재시작 기능은 포함하지 않습니다.

## 실행 환경
Cloudflare Workers + Vinext + React + D1 + R2. 기존 Sites 인증 헤더와 호스팅 통합을 사용합니다. 일반 Node 서버에서 그대로 운영하는 구조는 아닙니다.

## 개발
`pnpm install --frozen-lockfile` 후 `pnpm dev`로 시작합니다. Sites 전용 실행 스크립트가 포함되어 있으므로 Sites 프로젝트 설정과 DB 마이그레이션이 필요합니다.

## 배포 설정
호스팅 환경에서 DB, BUCKET 바인딩과 CAREER_OWNER_EMAIL, CAREER_OWNER_KEY를 설정해야 합니다. 인증 헤더는 신뢰할 수 있는 인증 게이트웨이에서만 주입해야 합니다. 새 배포의 프로젝트 ID와 설정은 별도로 생성하세요.

## 개인정보
지원서 PDF, 추출한 개인정보, 데이터베이스 내용, 인증키, 기존 사이트 ID는 이 소스에 포함하지 않습니다. 업로드 자동 생성은 규칙 기반 초안이며 AI API를 사용하지 않습니다.
