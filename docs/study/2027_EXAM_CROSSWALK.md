## 1. 필기 전체 주요항목 대응표

> **표기**: 개념서 페이지는 책의 인쇄 페이지, 복습집 페이지는 복습집 인쇄 페이지. 페이지가 특정 개념의 언급을 의미할 수는 있어도 원문 전체 세세항목의 완전 충족을 의미하지 않는다.

| **5. 최신 보안 동향** (11쪽) | ① **양자내성암호·동형암호·경량암호의 이해** ② 이들 기술의 **동향** 파악 | 기존 개념서 양자 위협만 부분 언급; **세 기술 비교·원리·표준 현황 신규 우선** |

**주의:** 딥페이크 AI는 **필기 정보보안 일반 4쪽**의 최신동향에 명시. 실기 11쪽의 최신동향에는 **양자내성암호·동형암호·경량암호**가 명시. 용어가 인접해도 필기·실기 원문 배치가 서로 다르다.

## 4. 갭 평가의 증거와 한계

- 기존 개념서에 **가상화·컨테이너·클라우드 책임 분담**(24쪽), **API 인가**(50쪽), **제로 트러스트**(41쪽), **양자 위협**(71쪽)이 있으므로 해당 큰 주제 전체를 '완전 미수록'이라고 하지 않는다.
- PDF 본문 검색 결과 **Trivy / ScoutSuite / SASE / ZTNA / XDR / VPC / Security Group / OWASP API / 동형암호 / 경량암호**의 이름은 두 기존 PDF에서 찾지 못했다. 명시 이름의 부재는 **강화 필요의 증거**이지 다른 관련 학습 내용이 전혀 없다는 뜻은 아니다.
- 학습자료의 최신 여부와 **공식 출제기준의 법적 효력**은 별도이다. 법령의 기간·수치, 보안 도구 옵션은 최신 공식 출처 확인 후 교정한다.
- 실습 명령과 자체 문제는 허가된 개인 실습 환경에만 사용. 침해, 우회, 정보수집에 쓰지 않는다.
