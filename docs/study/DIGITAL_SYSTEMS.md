# 디지털시스템 학습 노트 (정보보안기사 + 개발 준비)

디지털시스템 핵심 주제와 보안·개발 실무 연결 정리. 이 저장소의 암호화·WebAuthn 코드를 읽을 때 필요한 기초이기도 하다.

| # | 주제 | 핵심 내용 | 보안 연결 |
|---|------|-----------|-----------|
| 01 | 수 체계와 데이터 표현 | 2·8·10·16진법, 2의 보수, 부동소수점, 인코딩 | 정수 오버플로우, 인코딩 우회, 엔디안 |
| 02 | 논리 게이트·불 대수 | AND/OR/NOT/NAND/NOR/XOR, 드모르간, 카르노 맵 | XOR 스트림 암호, 패리티, 비트 마스킹 |
| 03 | 조합·순차 회로 | 가산기, MUX, 디코더, 플립플롭, 레지스터, FSM | LFSR 난수/스트림, 프로토콜 상태 혼동 |
| 04 | CPU 구조와 명령어 | ALU, 제어장치, 명령어 사이클, 파이프라인 | BOF, ROP, 투기적 실행/사이드 채널 |
| 05 | 메모리 계층과 캐시 | 캐시 매핑, 지역성, 가상 메모리, 페이징 | 캐시 타이밍 공격, NX/ASLR |
| 06 | 입출력과 인터럽트 | 폴링, 인터럽트, DMA, 버스 | DMA 공격, Race Condition |

## 4주 학습 순서

1. **1주차** 수 체계·논리: 진법/보수 연산, 게이트, 불 대수 간소화
2. **2주차** 회로·상태 기계: 조합/순차 구분, FSM 작성, LFSR 구현
3. **3주차** CPU·메모리: 명령어 사이클, 스택 구조, BOF 실습
4. **4주차** 입출력·종합: 인터럽트/DMA, 기출 문제와 약점 복습

## 실습 아이디어

- 진법 변환기와 비트 연산 연습 스크립트
- XOR 스트림 암호와 LFSR 직접 구현
- C로 스택 버퍼 오버플로우 재현 후 메모리 맵 확인
- 캐시 친화/비친화 배열 순회 속도 비교

## 시험 대비 습관

- 개념마다 "무엇이 깨지면 어떤 공격이 가능한가"를 한 줄로 기록
- 용어는 영문 원어와 함께 암기 (Race Condition, Side-channel 등)
- 기출 오답 이유를 해당 주제에 되돌려 기록
- 매주 마지막 날 약점 주제만 재풀이
