## 10월 6일 상세

### 오리역 vs 죽전역 → 수서역

수인분당선의 수서 방향 역 순서는 **죽전 → 오리 → 미금 → 정자 → … → 수서**입니다.

- 전철 구간만 비교하면 **오리역이 죽전역보다 1정거장, 약 3분 유리**합니다.
- 두 역까지 접근 시간이 비슷하면 오리역을 우선합니다.
- 죽전역이 집/출발지에서 3분 이상 더 편하면 죽전역을 이용하는 편이 전체 이동시간상 낫습니다.
- 현재 계획 예시: 죽전 08:02 / 오리 08:05 전후 상행 열차 → 수서 08:31 전후 도착 목표.
- 실제 전동열차 시각은 당일 코레일/역 전광판에서 다시 확인합니다.

### 부산 도착 후

1. 12:01 부산역 도착.
2. 부산역 1호선 → 서면역 환승 → 2호선 장산 방면 → 해운대역.
3. 신라스테이 해운대 도착 후 체크인 전이면 짐 보관.
4. 점심 후 15:00 체크인.
5. 샤워/환복/휴대전화·보조배터리·모바일티켓 점검.
6. 15:45 전후 호텔 출발 → 해운대역 → 센텀시티역 → 영화의전당.
7. 16:20~16:30 영화의전당 도착.
8. 개막식 종료 후 지하철로 해운대 복귀.

## 개막식 복장/준비물

- 스마트캐주얼: 긴팔 셔츠 또는 얇은 니트 + 슬랙스 + 얇은 재킷/블레이저.

- 야외 저녁 일정이므로 얇은 겉옷 필수.
- 휴대전화, BIFF 모바일티켓, SRT 승차권, 신분증, 교통카드.
- 보조배터리와 충전 케이블.
- 작은 접이식 우산.
- 개인 세면용품.
- 개막식에는 캐리어를 가져가지 않음.
- 10/7 영화 사이 시간이 촉박할 수 있으므로 에너지바/간단 간식 준비 권장.
